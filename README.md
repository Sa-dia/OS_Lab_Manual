# 📚 Course Files and C++ Code

This repository contains the **Word files** and **C++ source code files** for the course.

## 📂 Files

### 📄 Word Files

The Word files contain the course materials, assignments, lab tasks, and other documentation.

To access them:

1. Open the repository.
2. Go to the **Word Files** folder.
3. Select the required `.doc` or `.docx` file.
4. Download the file.
5. Open it using **Microsoft Word** or **Google Docs**.

### 💻 C++ Code Files

The C++ files contain the implementations of the programming and lab problems.

To access them:

1. Open the repository.
2. Go to the **C++ Code** folder.
3. Select the required `.cpp` file.
4. View the source code directly on GitHub.
5. Download the file if you want to run it on your computer.

## ⬇️ Download All Files

To download all Word files and C++ code at once:

1. Click the green **Code** button.
2. Select **Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the extracted folder to access all files.

## 🔧 Running the C++ Code

You can run the `.cpp` files using:

- Code::Blocks
- Visual Studio Code
- Dev-C++
- GCC/G++ compiler
